# 把这条提示词发给 Codex 开始做微信助手

## 你现在做这五个动作

1. 在电脑上新建一个空文件夹，例如“我的微信助手”。
2. 在 Codex 中建立或打开一个可访问本机文件的项目，选中这个文件夹，作为本次开发的位置。
3. 在该项目新开对话，把下面的开工总提示词完整复制进去。
4. 等 Codex 先复述使用流程、检查电脑并实际打开第一个小窗口，按照它给出的办法试一下。
5. 把试用结果告诉它。当前阶段通过，再回复“继续下一阶段”。出错时发排错提示词，沿用同一项目。

准备你自己的模型 API，密钥稍后在本机设置填写，不贴给对话。当前案例按 Mac 路线优化，当前原型构建目标为 Apple Silicon 和 macOS 15.2 以上；你的电脑先由 Codex 检查，Windows 另选实现路线。

这条提示词会开始开发第一阶段，后面仍需你实际试用和反馈；没有在另一台电脑从零完整复跑，不保证一次成功。

## 开工总提示词

```text
请在当前项目文件夹中，帮我从零做一个能在这台电脑上运行的“微信 AI 回复助手”。你负责写代码、构建和排错，不只给我方案。

我想借鉴 Codex 输入框预测建议的顺手体验。实际使用过程是：我打开微信聊天，主动短按快捷键；助手读取我通过系统选中的微信窗口里当前可见的消息，分清我和对方，生成一条可编辑建议并自动复制；用不抢走微信输入焦点的小浮层提示“已复制”，我自己按 ⌘V 粘贴、检查并发送。

请先用简短的用户操作流程复述你的理解。先检查这台电脑的系统、开发工具，以及你能否实际创建文件、编译和启动本机应用；有影响实现路线的缺项再问我。Mac 优先原生方案；如果是 Windows，重新选择该系统适用的方案。

按这六个阶段推进：①环境和最小窗口；②一句话改写、真实模型配置、编辑与复制；③虚构聊天截图识别；④可修改快捷键和单个微信窗口连接；⑤固定版本安装与集中授权；⑥实际读取、生成、复制、由我粘贴验收。每次只实现当前一阶段，运行给我试用；我反馈通过后再继续。每阶段在“构建记录.md”记下启动方式、版本、真实结果、问题和下一步。

实现时请提前处理这些问题：
1. 模型地址和名称按我实际服务商配置；密钥只在本机安全输入。启动先显示界面，不读钥匙串；需要时由我主动解锁。取消确认仍能继续操作。
2. 识别排除会话列表、按钮、时间、媒体卡片和未发送草稿；检查普通、放大、窄窗口、长消息、浅灰气泡与顶部视频遮挡部分分隔线。动态识别布局，不写死屏幕坐标；空白、全透明或识别不确定时停止。
3. 快捷键先尝试 Control＋Shift＋R，并提供能显示系统实际收到按键的设置入口。注册成功和本人实际触发分别验证。
4. 每次刷新同一微信窗口的身份与尺寸，截图前隐藏助手浮层。等待模型时聊天发生变化，不复制旧建议。只在我主动触发时读取。
5. 先离线检查，再安装到固定路径，保留配置和旧版回退。核对当前运行版本及其授权，不反复重装或让我开关权限；系统密码和登录由我本人完成。
6. 先用虚构会话；实际聊天文字交给模型前告诉我接收服务。建议保持原意，不替我编造承诺、经历或时间。日志不记录密钥和聊天正文，诊断图只在我明确保存时留在本机。

现在请开始第一阶段：复述使用流程、检查环境，实际创建并启动最小窗口。做到后告诉我怎么试，先不做后面阶段。
```

## 第一个窗口出来以后怎么回复

能正常打开：

```text
这个窗口已经能正常打开。请保存当前进度，继续下一阶段，做好后运行给我试用。
```

遇到问题：

```text
我刚才做了【我的操作】，预期看到【应该出现的结果】，实际出现【现象或截图】。请先看当前版本和对应阶段日志，定位这次失败的环节，沿用原项目做最小修复。不要从头重做、重复索取配置或反复让我开关权限。修好后带我复试，每次只给一个需要本人完成的动作。
```

## 先对焦使用方式时发这一段

```text
我希望把操作留在微信聊天里：我主动短按一个快捷键，你读取我选定窗口当前可见的聊天，分清谁说了什么，生成一条回复建议并复制。用一个不抢焦点的小浮层显示结果，我自己粘贴、修改和发送。

现在先用两三句话复述你理解的使用流程。然后告诉我，当前可运行的最小版本先做到哪里，我要怎么试才知道做对了。
```

Codex 的本机项目可以附加文件夹，新对话以主文件夹开始。[OpenAI 官方项目说明](https://learn.chatgpt.com/docs/projects#use-local-projects-for-folders-and-codebases)。
