# 微信 AI 回复助手：从一个小念头开始

**灵姐说 AI / Ling Talk AI 节目配套资料：完整构建提示词、使用说明和踩坑记录。**

这期的灵感来自我在 Codex 里用到的预测建议：输入框先给一条我可能想发的提示，按 Tab 接受后，还能修改再发送。我用着用着就想到：这种“先给建议、我看过再用”的体验，能不能也带进微信？

我把具体想怎么用讲给 Codex，逐步做成自己会用的 Mac 微信 AI 回复助手。灵感来源官方叫 [Composer Predictions](https://learn.chatgpt.com/docs/features/composer-predictions)，这里分享从想法到工具的过程。

[下载完整资料包 · v1.0.0](https://github.com/Carolyn-ai/wechat-ai-reply-guide/archive/refs/tags/v1.0.0.zip)

## 马上开始一件小事

1. 新建空文件夹，在有本机执行能力的 Codex 项目中打开。
2. 发 [开工总提示词](prompts/00_复制给Codex开工.md)。
3. 先检查电脑，实际打开第一个小窗口。
4. 自己试过当前阶段，再继续。详见 [资料使用说明](docs/01_怎么使用这套资料.md)。

提示词会开始开发，后面仍需试用和反馈，不保证一条提示词一次完成。

## 这个助手怎样用

Control＋Shift＋R 主动唤起 → 读取选中窗口可见聊天 → 生成建议并复制 → 本人粘贴、检查、修改和发送。

这是自制 Mac 工具，不是微信官方功能。Tab 接受建议发生在 Codex，微信助手使用独立快捷键。

## 适用范围

原型按 Apple Silicon Mac、macOS 15.2及以上构建；先让 Codex 检查自己的电脑。Windows 需要新的实现路线。

普通窗口有真实生成复制及本人粘贴记录；放大窗口有生成复制记录。窄窗口、真正全屏和跨显示器有未验收项；联系人记忆是扩展，基础原型未实现；另一台电脑从零完整复刻尚未验证。

首版提供提示词和说明文档，需要在自己的电脑创建、配置和试用应用；没有附可安装程序。

## 配置与反馈

模型密钥在本机填写；识别后的聊天文字发给自己配置的模型服务。先确认接收对象，公开反馈用 [虚构问题模板](docs/05_反馈问题.md)。
