# 拿到资料以后，先做什么

## 五个动作

1. 在自己的电脑上新建一个空文件夹，例如“我的微信助手”，用来保存自己生成的应用。
2. 在能操作本机文件的 Codex 项目中，把这个文件夹设为主文件夹，再新建对话。
3. 打开 [开工总提示词](../prompts/00_复制给Codex开工.md)，复制“开工总提示词”代码框中的全文。也可用 [纯文本版](../prompts/00_复制给Codex开工.txt)。
4. 让 Codex 先复述怎样使用，检查电脑，并实际创建、启动第一个小窗口。
5. 自己试过当前阶段后，再发“继续下一阶段”；失败时，用 [排错提示词](../prompts/02_排错与换对话续接.md) 描述操作、预期和实际结果。

已有项目可在项目菜单的 Edit project 中添加文件夹并设为主文件夹。设置依据见 [OpenAI 官方项目说明](https://learn.chatgpt.com/docs/projects#use-local-projects-for-folders-and-codebases)。

对话能回答问题，不代表当前环境一定能创建文件、编译和运行应用。第1阶段应以实际打开窗口证明，不接受只给代码片段就算完成。

## 两种跟做方式

默认发送总提示词，让 Codex 每次只做当前阶段；想逐条控制时，按 [六阶段跟做卡](../prompts/01_六阶段跟做.md) 每次发一步。两种方式指向同一条基础路线。

早期六步需求参考用于理解构思；跟做以当前基础路线为准，扩展功能在跑通以后再加。

| 阶段 | AI应交出什么 | 本人试什么 |
|---|---|---|
| 1 环境和小窗口 | 在电脑实际启动最小应用 | 窗口能打开 |
| 2 改写和模型配置 | 真实生成、编辑、复制 | 改一句话，粘贴到空白文档 |
| 3 虚构聊天识别 | 正文、顺序、我/对方方向 | 侧栏与未发送草稿没有混入 |
| 4 快捷键和单窗连接 | 可改快捷键、选窗入口、浮层 | 注册与实际触发分开记录 |
| 5 固定安装和授权 | 固定安装版、配置保留、回退 | 当前版本实际取得非空窗口图 |
| 6 真实流程 | 建议生成并复制 | 本人粘贴为草稿，逐种布局测试 |

## 第一个窗口正常以后

```text
这个窗口已经能正常打开。请保存当前进度，继续下一阶段，做好后运行给我试用。
```

## 电脑与模型准备

原型按 Apple Silicon Mac、macOS 15.2及以上构建。先让 Codex 检查自己的电脑、工具和本机执行能力；Windows 需要新的实现路线，Mac 的权限步骤不能直接照搬。

准备自己的模型接口。服务地址和模型名称以服务商当前提供的信息为准；密钥只在本机设置里输入。Codex 使用条件和助手配置的模型接口是不同事项，各自以账户实际规则为准。

下载资料以后，仍需在自己的电脑构建、试用和排错。尚未在另一台电脑从零完整复跑，不保证一次成功。
