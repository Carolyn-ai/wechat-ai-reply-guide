# 做出助手以后怎么用

以下是本期 Mac 原型的交互目标；你生成的版本，以自己的项目记录和实际界面为准。

## 第一次准备

1. 从 Codex 记下的固定安装位置启动，确认当前版本。
2. 在本机模型设置中填写服务地址、模型名称和密钥。密码、系统确认与登录由本人完成。
3. 通过系统选窗，只连接需要的那个微信窗口。
4. 快捷键先用 Control＋Shift＋R（⌃⇧R）；有冲突再在设置中修改。
5. 先用虚构会话或专门的测试聊天，跑通一次流程。

## 日常一次使用

打开选定聊天 → 短按快捷键并松开 → 本机识别当前可见消息 → 将确认正文交给配置模型 → 浮层给出一条建议并复制 → 本人按 ⌘V 粘贴、检查、修改和发送。

建议不会自动发送。发送前确认意思，不让 AI 编造自己的时间、价格、经历或承诺。

## 变更窗口或聊天

窗口尺寸改变，要按当前布局识别；等待模型期间如果聊天变化，应停止复制旧建议。让 Codex 在自己的版本中实现并验证。窗口关闭或变成另一个窗口时，应重新选择连接。

普通、放大、窄窗口、真正全屏与跨显示器分别测试，不能用一个场景成功代表其他都通过。

## 结束和再次启动

不需要时关闭助手，下次从同一固定位置启动，沿用自己的配置。密钥解锁、关闭行为等以生成的版本为准，让 Codex 写进使用说明。

Tab 接受预测草稿是 Codex 的 Composer Predictions；微信助手借鉴它的体验，实际用独立快捷键读取、生成和复制。
