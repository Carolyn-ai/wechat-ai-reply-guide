# 隐私与模型配置

本期原型只在本人主动触发时读取所选微信窗口当前可见消息，不读取微信数据库，也不后台翻查完整历史。

截图先在本机识别；生成所需的聊天文字会交给自己配置的模型服务，不等于聊天内容一直留在本机。使用前让 Codex 说清接收服务和发送内容。

密钥只在本机设置中填写，不放入 Codex 对话、公开截图、GitHub、源码或日志。模型地址、名称和账户费用以自己的服务商当前规则为准。

启动先显示界面，需要时由本人主动解锁保存的密钥；取消确认后仍可继续操作。

诊断日志建议只记录阶段、数量、窗口尺寸和错误类型，不记录聊天正文、密钥与完整请求体。诊断图仅由本人主动保存，公开提问时换成虚构示例。

本项目是个人开发案例，不表示微信官方功能或授权合作。
