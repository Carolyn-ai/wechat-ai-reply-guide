# 排错与已知限制

## 先定位失败环节

按键触发 → 窗口核对 → 截图 → 识别 → 模型 → 复制 → 本人粘贴。

| 现象 | 给 Codex 的具体反馈 |
|---|---|
| 按了没反应，或触发别的功能 | 核对实际收到的组合、注册和本次本人触发记录。 |
| 找不到微信窗口 | 核对连接对象与尺寸，窗口变更后重新选择。 |
| 权限开着仍无截图 | 核对运行版本、固定路径、对应授权；用当前版非空图验证。 |
| 截图空白或透明 | 本机查质量，停止后续识别与模型请求。 |
| 找不到聊天区 | 用本次本机诊断图，核查窄窗口、媒体贴边、分隔线遮挡。 |
| 模型生成失败 | 核对服务地址、模型名称、账户状态和错误类型；密钥不贴到对话。 |
| 已复制但粘贴无文字 | 单查复制和焦点，先在空白文档试。 |
| 建议对应旧聊天 | 停止复制旧结果，检查请求前后聊天变化。 |

诊断图只在本人主动保存时留在本机；公开反馈优先使用虚构聊天。完整 [排错与续接提示词](../prompts/02_排错与换对话续接.md) 可直接复制。

## 本项目实际记录到哪里

以下仅说明本期原型已有的使用结果；每台电脑仍需独立验证。

| 场景 | 已有结果与边界 |
|---|---|
| 普通窗口 | 真实读取、生成、复制有记录；本人粘贴为草稿也已确认。 |
| 放大的同一窗口 | 有多次生成和复制记录；粘贴环节未单独完整验收。 |
| 侧栏收起的窄窗口 | 有离线样本，缺现场通过记录。 |
| 真正全屏 Space、跨显示器 | 尚未完成现场验收。 |
| 联系人独立记忆、长期风格学习 | 属于选做，基础原型未实现。 |
| 另一台电脑从零复刻 | 没有完整复跑记录。 |

已知坑被提前写入开发要求，仍需自己试用。离线检查、能构建、窗口能打开和日常流程成功是不同结果。

## 更新和回退

保留配置与旧版回退，固定安装位置。临时签名更新可能需要再次确认权限；先核对版本和实际失败环节，再处理对应授权，避免同次验收中反复覆盖应用。
